# Проект автоматизации веб-приложения https://stellarburgers.nomoreparties.site
1. Основа для написания автотестов — фреймворк pytest и Selenium
2. Установить зависимости — pip install -r requirements.txt
3. Команда для запуска тестов  pytest tests/имя_тестового класса, например  pytest tests/test_logout.py
